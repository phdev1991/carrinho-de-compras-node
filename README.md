# 🛒 Carrinho de Compras Node.js

Serviço de carrinho de compras em Node.js com operações assíncronas: adicionar, remover e deletar itens, calcular subtotal e total, e exibir o carrinho formatado. Projeto de estudo focado em manipulação de arrays, escopo de funções e módulos ES6.

## ✨ Funcionalidades

- ➕ **Adicionar item** ao carrinho
- ➖ **Remover quantidade** de um item específico
- 🗑️ **Deletar item** completamente do carrinho
- 💰 **Calcular total** do carrinho (soma dos subtotais)
- 📋 **Exibir carrinho** formatado no console
